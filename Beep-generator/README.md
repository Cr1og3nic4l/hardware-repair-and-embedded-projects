## Soundboard Beep Generator (2025)

**Description**  
DIY electronic soundboard project based on logic ICs. Generates various beeps and tones using CD4011 (quad NAND gates) and CD4066 (analog switches).  
Perfect for audio experiments, simple alarms, or as a foundation for more advanced embedded projects.

**Features**
- Main components: CD4011, CD4066, resistors, capacitors, piezo speaker, tactile switches
- Custom PCB with speaker footprint and pin headers
- Hand-soldered assembly
- Functionality: basic acoustic signal generation (beeps and tones)
